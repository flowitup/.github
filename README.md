# `.github`

This repository hosts org-level metadata for **flowitup**.

The interesting file is [`profile/README.md`](./profile/README.md) — GitHub renders it on the
[`flowitup`](https://github.com/flowitup) org page.

## Layout

```
profile/
  README.md             # rendered on https://github.com/flowitup
  assets/
    banner-light.svg    # hero banner, light mode
    banner-dark.svg     # hero banner, dark mode
```

To preview a change, edit on a branch and look at the Markdown preview in the PR.
